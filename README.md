# TAV IMPORT

Интерактивный frontend-прототип сайта поставщика промышленного оборудования из Азии.

## Возможности

- адаптивная главная страница в тёмной индустриальной стилистике;
- отдельные страницы для шести направлений поставок;
- форма предварительного расчёта;
- подборка оборудования;
- виджет консультанта;
- подготовленная конфигурация для OpenAI Sites.

## Локальный запуск

```bash
npm install
npm run dev
```

Сайт откроется по адресу `http://localhost:5173/`.

## Проверка

```bash
npm run build
npm run test:sites
```
